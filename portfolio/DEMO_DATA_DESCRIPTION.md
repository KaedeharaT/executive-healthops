# Portfolio 演示数据说明

本作品集只使用 `scripts/build_portfolio_demo.py` 生成的隔离数据：`data/portfolio_demo.db`。该文件默认被 Git 忽略，不包含真实成员资料。

- 主成员：`Demo Executive A`（匿名化演示身份）
- 体检：`2024年度综合体检报告（演示）`，为原创结构化 fixture；它借鉴常见体检项目的展示结构，不是原始报告副本，也不附带 PDF。
- 证据：展示页码、区块、数值表格和原始片段的可追溯链路；内容均为演示 fixture。
- 风险：仅有明确标记的 TEST / 演示规则，用于展示分流与人工工作流；不存在 Clinical RiskRule。
- 知识：MedlinePlus、RxNorm、openFDA 的演示元数据仅用于展示来源、审核与引用治理；官方内容为按需查询，不镜像完整外部内容。
- 设备：连续健康数据和设备状态为演示数据。Apple Health 桥接源码存在，但未进行真机验证。

作品集不得导入真实姓名、联系方式、身份证件、原始检查文件、账户、地址或其他直接身份标识。
