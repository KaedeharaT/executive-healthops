# Executive HealthOps 作品集演示视频脚本

建议使用 Windows 录屏或 OBS 录制；全程约 3 分钟。启动前运行 `scripts/start_portfolio_demo.ps1 -Rebuild`，并使用 `Demo Executive A`。

| 时间 | 画面与操作 | 旁白 |
|---|---|---|
| 00:00–00:15 | Portfolio 首页，展示两个入口 | Executive HealthOps 是面向企业高管的 AI 辅助健康运营原型，把健康资料、人工协同和长期历程放在同一条可追溯链路中。 |
| 00:15–00:35 | 进入成员健康中心首页 | 成员首先看到当前状态、重点数据、近期变化和下一步，而不是内部工作流。 |
| 00:35–01:05 | 健康 → 体检，选中 `2024年度综合体检报告（演示）` | 体检报告经规则解析与本地 Qwen 语义辅助整理为关键指标、主要发现、建议随访和人工确认项。 |
| 01:05–01:25 | 打开 LDL-C 或胸部 CT 的“查看依据” | 每项结论都可回到匿名化报告的页码、检查区块和原始片段；系统整理不替代原始资料。 |
| 01:25–01:45 | 回到健康概览，展示健康基线；进入运营后台今日 | 体检资料在人工确认后进入健康基线。确定性演示规则只负责风险分流，黄色事项进入健康管理师工作列表。 |
| 01:45–02:05 | 医疗协同 → 内部医生，打开 Review | 需要医学判断的内容由内部医生复核。AI 不诊断、不处方，也不决定风险等级。 |
| 02:05–02:25 | 成员端 历程 | 连续设备数据以趋势和阶段总结呈现；报告、风险、管理干预和结果汇聚成长期健康历程。 |
| 02:25–02:45 | 更多 → 知识库 | 医学知识中心区分在线来源、已保存资料和人工审核。只有已批准资料才可作为正式 AI 引用来源。 |
| 02:45–03:00 | README 架构图或平台首页 | 工程上采用 Streamlit、FastAPI、SQLAlchemy、Alembic 和本地 Qwen；当前仍是研究型作品集原型，临床规则和真实设备连接需进一步验证。 |

录制检查：不展示浏览器个人资料、文件目录、终端、真实上传报告、API token 或本地数据库路径。
