# HealthOps V5 使用逻辑验收

## 实际使用路径

- 健管：今日工作统一找事，点击直接处理；会员列表搜索找人，点击进入唯一 Member360。
- 健康管理助手：今日工作始终可见。等待健管时提供继续处理；等待医生时明确提交后自动继续。报告、确认、医生判断、行动建立仍由现有 Agent V1 驱动。
- 医生：待我判断 / 历史。点击问题提交判断后，健管在今日工作继续确认后续安排。
- 年度管理：全局查看，点击进入 Member360 管理页；保留返回年度管理。
- 医疗协同：全局和会员内使用同一医疗详情；复查与服务执行也可以直接从今日工作处理。
- 成员：首页、健康、计划、服务、历程；不展示工作人员自动化配置。
- 管理员：系统状态、自动化运行、数据与集成、规则与知识。原有配置和兼容工具保留。

## Before → After

| 以前 | 现在 |
|---|---|
| 需要知道报告、任务、自动化的模块位置 | 所有人工动作进入今日工作统一表格 |
| 自动化不易发现 | 健康管理助手固定出现，最多展示三条重要进度 |
| 点击工作后还需要找列表和会员 | 一击进入当前事项详情 |
| 医生返回后人工寻找结果 | 原流程自动恢复，行动确认重新进入今日工作 |
| 会员资料入口分散 | 搜索并点击会员行，进入唯一 Member360 |
| 年度管理重复会员详情 | 直接进入同一个会员的管理页 |
| 医生端混有多个业务模块 | 只有待我判断和历史 |
| 健康档案长列表与重复展开 | 资料摘要表，点击进入单项详情 |
| 日志和后续待办需要分别填写 | 保存时准备后续待办，一次确认正式建立 |
| 返回容易丢失工作来源 | 今日工作、会员、年度管理保留明确返回来源 |
