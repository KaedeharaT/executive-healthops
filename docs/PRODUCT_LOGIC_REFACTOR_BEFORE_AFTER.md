## 保留核对

102组业务要素：KEEP 77、GROUP 11、MOVE 7、MERGE 5、ADVANCED 1、LEGACY ACCESS 1。COLLAPSE和SECONDARY本轮没有作为主处理类别新增；既有折叠和次级入口仍保留。Deleted 0，Missing 0，Preserved 102/102。

底层1390个UI调用点作为改动前快照逐项编号；这是模板/调用点数量，不是1390个独立页面。348个原函数、280个既有控件key表达式与66个API路由契约全部保留。控件文案与布局可以合并、调整，不能用调用点数量下降等同功能删除。完整清单见 [保留映射](PRODUCT_LOGIC_PRESERVATION_MAP.md) 和 [机器可读快照](product_logic_elements.json)。

没有删除图表、报告上传、确认、比较、基线/修订、健康数据、用药、问题、服务、随访、结果、时间轴、AI、Agent、知识、设备、规则、反馈、审计、API或高级诊断。15个历史兼容工具继续在管理员 → 系统状态 → 高级信息·兼容工具。

## 导航与写入边界

成员：首页/健康/计划/服务/历程；健管：今日/成员/医疗协同/服务/更多；医生：队列+状态筛选；管理员：集成与数据/自动化运营/规则与知识/系统状态。角色一级导航最多5项，业务导航2层，成员详情中的资料切换是同页详情，不新增独立业务导航层。旧“健康数据/用药与医疗”等跳转显式映射到两种角色的实际标签，历程选择的时间范围继续传递。

成员任务：导航首页 → 去完成 → 确认完成。健管：今日 → 处理 → 上下文动作；成员360的计划/随访/阶段结果快捷动作仍保留。医生：待复核 → 选择问题 → 提交判断。管理员：集成与数据 → 检查 → 配置/测试。表单字段填写不计为导航点击。

风险阈值、基线确认/冻结/修订服务、医生责任、Evidence语义和Timeline事实来源未改；没有数据库迁移或设备/Agent新能力。报告API现在产生与原UI相同的年度初稿副作用，已确认年度基线保持冻结。
