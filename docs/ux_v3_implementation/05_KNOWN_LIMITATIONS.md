# UX V3 范围与验收边界

- READY指此轮角色体验和合成Portfolio流程可演示，不意味着真实身份认证、真实设备/合作方连接或临床生产资格。演示角色切换仍明确标注。
- 页面里的当前日期、逾期和时间范围使用实际时钟；合成数据的历史趋势不会被挪成“今日真实测量”。无未来服务不会显示过期预约为下一安排。
- “今天待处理”是当前工作队列的今日截止统计，不是已登录个人认领统计。现有身份机制未在本轮改动。
- 完整健康档案、复杂医学确认、审核和兼容工具依然可能较长；核心页仅呈现摘要，详情允许展开。没有用折叠代替权限控制。
- 管理员连接状态严格区分配置存在、测试记录和已验证真实连接；本轮没有联系外部模型、厂商或知识合作方完成真实连接认证。
- 图表轴线/刻度/单位/基线/当前值经实际截图检查；图表测试只补充结构回归，不能独立证明肉眼可读。
- 浏览器验收使用Playwright启动的真实Chromium。内置Browser运行时发现结果为空，未假称使用内置浏览器会话。截图为实际viewport；另存滚动到图表/判断区和640px窄屏截图，未合成页面视觉。
- “10秒理解”和“5分钟故事”按设计阅读顺序、动作可达性与演示路径核查，不是招募真实用户后的计时可用性研究。
- 元素保留口径是冻结的121个业务/导航/兼容分组，含父子条目；不冒充121个独立业务模块。每组核对原渲染器和新位置，运行验证覆盖主要角色路径、15个Legacy工具及既有测试，不声称每种数据排列/网络失败组合都已穷举。
- 未修改README、研究历史记录、生产部署、数据库Schema、临床规则或Agent医疗权限；没有push。
