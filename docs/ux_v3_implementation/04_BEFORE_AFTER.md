# UX V3 Before / After

比较起点为备份分支，历史图片保留在 `docs/images/product-logic-v3/`。本轮图片在 `docs/images/ux-v3/`；不把历史截图标成此次截图。

|冻结问题|Before|After|能力去向|
|---|---|---|---|
|F01 医生阅读顺序|结论表单与背景并列，可能先看到提交|问题、相关趋势和依据在表单之前|结论/责任交接仍是原业务命令|
|F02 今日口径|“今天”包含未来及无截止事项|本地日期明确统计；无日期与未来事项仍在完整队列|没有过滤掉待办事实|
|F03 事项处理|长行含负责人；通用处理|短行明确优先级、状态、截止；右侧具体业务动作|报告、风险、计划、服务、审批均可进入原上下文|
|F04/F05 健康信息次序|筛选器先于基线比较|起点与当前比较先出现，再选择主趋势|全指标表/所有旧图仍在详情|
|F06 360抬头|两组摘要及重复关注|一条周期/阶段/负责人/更新时间；关注与下一步只摘要一次|完整关注在健康/处理详情|
|F07 健康导航重复|360五区再叠一排健康菜单|360五区保留；健康默认主趋势，具名资料按钮内选择详情|数据、体检、基线、健康史仍可达|
|F08 管理员默认配置|进入直接展开上传|系统状态默认；连接状态→选择→配置|导入及全部连接配置保留|
|F09 医学指标截断|四列固定指标、长名截断|本次问题相关趋势优先；全部关键指标表放详情|不丢失原指标|
|F10 结果归属|旧计划结果与当前计划并排|当前计划结果优先，历史结果明确折叠|所有历史结果仍可查看|
|F11 重复设备配置|规则区与集成区各出现配置|旧设备入口明确跳到集成同一配置|兼容入口保留|
|F12 页面解释自己|管理顺序长说明|阶段和任务顺序承担表达|必要医学边界说明保留|
|F13 双滚动队列|固定540px内滚动+外滚动|自然页面流，前6项及具名其余事项|完整队列保持可选|
|F14 首页多个快捷按钮|每张趋势一个按钮+底部三按钮|一个变化入口；计划/上传快捷保留在管理详情|无数据时上传可成为主动作|
|F15 元信息过小|多处约13px|共享元信息14px、正文16px、按钮44px|正式图表坐标轴配置原样保留|

没有回滚UX、删除后端功能或新建医学能力。原函数兼容合同由原保留测试继续检查；121项设计元素归属结果见02。
