# UX V3 · 最终信息架构候选

本轮仅设计；以下路由为拟议位置，不表示已调整应用。三个核心逻辑为健康状态、健康运营、长期记录；支撑层不与成员业务平铺。只设计六个核心页面，其余在此明确归属，不另画几十页原型。

## 层级/可找到性定义

- 一级是角色主导航；二级是页面视图。成员360中的五种详情是同一成员页的局部状态，不再继续套一排子导航；用具名折叠/资料链接代替第三层菜单。
- “高级/兼容”是管理员系统页内展开区，不是新主菜单。即使不计作导航，点击成本仍单独核对，禁止靠定义掩盖深度。
- 常见动作目标≤3次导航/选择点击到现有表单：成员首页→主行动→任务；今日→选工作→处理；医生待复核→问题→表单（滚动核对依据）；管理员系统状态→选集成→配置。**表单填写/强制确认步骤不伪称都能三次点击完成**，不为点击指标省略医学核对。
- 旧别名：体检→体检与检查；医疗档案→健康档案；工作列表→今日；旧风险规则/操作记录→管理员对应位置。保留返回原成员及筛选；不更改历史数据或URL中的身份语义。
