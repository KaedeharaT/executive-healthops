## 一条事实，四种展示目的

以医生复核为例：今日显示“下一责任人/依赖”；360 显示该成员当前管理阻点；医生显示待回答的问题与依据；完成后时间轴展示人工结论事件。四处引用同一记录，不再四处都展示完整详情/编辑表单。

## 渐进披露规则

1. 先判断是否需要行动；L1 永不藏在高级信息。
2. 帮助理解当下的 L2 留在摘要或主图，不另开仪表盘。
3. L3 通过有名称的“检查结果 / 用药与病史 / 查看依据 / 数据记录”进入，不使用笼统“更多详情”承载全部。
4. L4 的业务状态可投影在上下文（如等待人工），配置/Trace 只在管理员；保留明确目录与兼容路径。
5. 折叠不改变数据、责任或业务状态；展开后仍沿用原业务命令，不造第二事实表。
