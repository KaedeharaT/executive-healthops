# 成员健康概览专项重构

范围：成员 → 健康 → 健康概览及必要展示组件。起点 `5bbe7d1`，备份 `backup/pre-member-health-overview-redesign`。不改变其他角色页面、医疗规则、基线事实、数据库或演示数据。

## 改动前核验

已实际打开成员健康概览和原年度基线详情。默认概览将关注事项放在趋势、两组折叠入口和主要按钮之后；完整基线详情逐领域输出“资料不足”，阶段仅是三列文字。指标表、选择器、图形、完整对比与资料入口权重接近。

改动前截图：`images/member-health-overview/before-desktop.png`、`before-desktop-full.png`、`before-baseline-detail.png`。

## 数据与阶段边界

- 年度基线、观测与比较仍使用原共享投影及统一图表；数值方向不解释为改善或恶化。
- 阶段来自基线确认状态及当前计划阶段/状态；无计划、待确认、暂停不能伪装成“持续管理中”。
- 重点关注使用原领域摘要及未关闭健康问题，不生成新风险等级。
- 补充资料沿用现有上传/待确认资料入口；已确认基线不会被成员输入直接覆盖。
- 原完整基线详情保留，包含参考范围图与历史年份。该兼容详情不属于本轮重新排版范围。

## 实际实施

- 新增 `ui/pages/member/health_overview.py`，原 `member/experience.py::overview` 仅委托它渲染；不增加 `streamlit_app.py` 代码。
- `ui/styles.py` 新增只在本页加载的样式，阶段条、关注列表、六格资料覆盖及窄屏单列均限定在本页组件。
- 统一基线趋势增加可选 `member_overview` 布局；默认布局不变，健管等页面继续按原方式显示。新布局仅比较选中指标；选择时间范围时，“当前”与图中最后有效点保持一致。
- 保留“当前健康状态”，按所选指标与时间范围显示实际最近记录日期，避免用其他指标的更新时间代替当前图形的数据时间。
- 当前领域状态、确认日期、负责人、阶段、数值和覆盖数均来自已有事实/投影。没有新增演示资料。
- 全量指标比较、领域完整说明、年度基线详情、用药/既往史、报告及健康数据入口在详细资料区默认折叠。
