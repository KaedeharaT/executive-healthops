# 健管实际怎么使用

1. 在“会员”新建会员并明确责任健管。健康管理助手会随会员长期保留，不用点击启动。
2. 在 Member360“健康档案”顶部上传现有资料。看板显示为什么开始、真实步骤、当前文件和下一步。
3. 整理完成后处理待确认、冲突和缺失信息，再确认初评。完整表格仍可用于查看和修正。
4. 从“今日工作”进入当前事项，在“本次处理结果”写一次随访或沟通记录。助手整理后，核对准备保存的日志和后续安排，一次确认。
5. 按页面给出的下一步继续。需要医生时等待医生，计划时间到了自动重新进入处理；阶段完成后核对自动汇总并确认下一阶段。

## 什么情况下需要我

资料不明确、有冲突、需要补充、要确认后续安排或阶段结果时，页面会明确显示需要您做什么。自动读取、整理中的内部步骤不会另建健管待办。

等待健管或医生时转圈会停止。进度不随时间自行上涨；本地 AI 请求进行时，整体进度停在当前真实步骤。处理异常时保留原文和人工核对路径。

## 医生和正式档案

助手不能诊断、开药、改药或决定治疗。会员说“准备去复查”只表示一项意向；没有可核对的医疗依据时，先形成协调事项。正式医疗事实继续经过原有确认流程。

## 手机与设备

以后接入手机和设备后，数据自动进入，无需点击分析或启动助手。每条原始测量不会叫醒助手；经过规则核对，确实有需要处理的变化时才进入管理流程。
