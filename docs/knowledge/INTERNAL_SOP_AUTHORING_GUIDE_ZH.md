# Internal SOP Authoring Guide

每份内部 SOP 必须标为 `Portfolio Training SOP` 或 `Internal Demo Training Material`，除非未来由真实机构正式发布。

必填结构：标题、适用范围、不适用范围、岗位/Owner、触发条件、顺序步骤、Due/复核点、升级条件、结束条件、禁止行为、事实依据要求、版本/生效日/复核日、supersedes。

内容以当前可测试的 HealthOps workflow 为基础，不创建医学阈值。健管不得诊断、处方、停药、调药或替代医生判断。Rubric 的 required/forbidden actions 必须绑定已批准 SOP Chunk；业务逻辑变更时先创建新版本并人工审核，不能静默覆盖旧版。
