# Clinical Rule Source Candidates

This is a review queue, not an active rule set. No source below creates or changes a `RiskRule`.

| Source | Potential use | Version/jurisdiction | Required governance |
|---|---|---|---|
| USPSTF recommendations | preventive-rule reference candidate | recommendation date / US | licence check, population mapping, clinical author and reviewer |
| NICE guidance | chronic-disease reference candidate | guidance version / UK | licence, UK applicability and medical review |
| WHO guideline publications | global public-health reference candidate | publication edition / GLOBAL | publication-specific licence and jurisdiction review |
| NHLBI/NIDDK government resources | educational rationale candidate | page/review date / US | distinguish education from clinical threshold |
| China NHC official guidance | CN workflow/reference candidate | document number/date / CN | official-text and licence check, clinician approval |
| Japan MHLW guidance | JP lifestyle/reference candidate | guide edition / JP | PDL/content check, clinician approval |

Required future rule provenance: `knowledge_document_id`, source version, effective date, rule author, medical reviewer, approved_at and valid_until.
