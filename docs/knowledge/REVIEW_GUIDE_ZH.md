# 知识审核指南

## 可以批准

来源真实可访问；用途、受众、国家/地区、版本、发布日期、许可和归因完整；正文与原始来源一致；Chunk 是完整知识点；不存在诊断、处方或自动风险动作；有效期和复核日期明确。

## 只能元数据或链接

付费/专业组织材料、许可不允许再分发的指南、Apple 等产品文档、法规原文，以及未确认版权的网页。公开可访问不等于可全文入库。

## 审核步骤

1. 打开官方原始 URL，不以搜索摘要或转载为依据。
2. 检查页面/出版物级许可、第三方内容、商业使用和翻译限制。
3. 核对 jurisdiction、language、audience、intended_use、禁止用途。
4. 核对版本、有效日期、review_due_at；冲突来源不得合并成无来源“标准答案”。
5. 抽查 Chunk 的标题、章节、原文位置和引用片段。
6. 以 `KnowledgeReviewAudit` 记录决定。新版本进入 `PENDING_REVIEW`，不得自动批准。

`APPROVED_SOURCE` 只表示来源可作为候选，不等于该来源所有内容自动 `APPROVED`。法律资料仅作设计参考，不构成合规结论。
