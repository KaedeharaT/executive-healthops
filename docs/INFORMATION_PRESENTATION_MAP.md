# HealthOps 信息表达规则与落地映射

基于 `63b2d7a` 的现有功能实施。本轮修改组件类型和只读列表投影，不改变数据库、医疗规则、任务状态机、医生责任或自动化权限。所有业务写入继续调用原有 Service。

## 表达规则

| 信息类型 | 默认表达 | 完整信息与操作 |
|---|---|---|
| 有效连续数值 | CHART：折线、真实日期、单位、坐标轴、Tooltip | 来源、原记录进入折叠详情；不足两点不连假趋势 |
| 基线与当前 | 紧凑对比 + CHART | 原年度基线、当前值和数值方向保持；不发明健康分数 |
| 批量工作事项 | TABLE | 选择行后 DETAIL，保留原业务操作 |
| 流程阶段 | STEPPER | 显示明确的当前阶段，不推断完成百分比或跳过步骤已经完成 |
| 时间事件 | TIMELINE | 摘要、时间、负责人；完整记录展开 |
| 少量关键事实 | SUMMARY | 状态、负责人、截止、下一步 |
| 长文本 | DETAIL | 不放进队列正文或长表格单元格 |

## 选择、排序和空状态

- `ui/presentation.py::data_table` 是本轮共享组件。原生 Data Grid 支持列排序、行选择；键盘下拉选择为替代输入方式，默认收起。
- 显示单元格最多 32 个字符，源对象没有被截断。完整来源、指令、结果、医生意见均通过所选记录详情访问。
- 表格以输入记录身份及内容生成选择版本；筛选或数据刷新后重新定位，避免用旧的行序号对另一条记录操作。
- 时间列保留日期类型并格式化显示，不把相对日期字符串当作数值排序。混合说明列明确降为文本。
- 今日工作默认继续使用原逾期／优先级／本日到期排序；增加全部、今天、逾期、高优先级、等待医生、等待会员、复查、服务筛选。
- 日志导出另取完整业务字段，包含当前筛选结果，避免导出展示用截短文本；CSV 单元格防公式解释。
- 空表仅一行说明，不生成大空白框。表格高度随行数增长，超过上限在表内滚动；未增加虚构统计图。

## 阶段数值语义

阶段图从同一 `HealthVisualizationService` 读取有效观测，按阶段起止日期并截止当前时间过滤。只有至少两个不同观测时间才绘图。表头使用“阶段内首条／阶段内最新”，不把年度基线冒充阶段开始，也不把阶段内首条记录说成阶段边界测量。没有连续记录时明确显示资料不足，不为截图制造数据。

## 保留边界

原 121 个元素的源函数及导航保留；新增真实健管流程的入组、问卷、初评、年度阶段、日志、复查、会诊、服务、结果和下一阶段继续调用原 Service。本轮没有 migration，没有更改模型、Risk、Baseline、医疗权限或健康图表轴组件。

验收图片、每页组件数量与实际浏览器结果见 `INFORMATION_PRESENTATION_QA.md`。
