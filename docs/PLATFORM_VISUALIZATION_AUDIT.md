## 统一实现

- `services/health_visualization.py`：只读、角色无关的时序投影，复用 canonical code 和单位转换，排除无效、删除、禁用记录；同单位后才比较。睡眠 Observation 优先，SleepSession 补充缺少的时长记录，不生成睡眠评分。
- `ui/charts/health.py`：复用已有 Altair，正式趋势都有时间轴、数值轴、单位、网格和日期/数值/单位/来源悬停。血压同轴双线，不同单位拒绝合图；单点只有数值和提示。
- `ui/pages/health_visualization.py`：共享选择器、时间窗口、预览跳转、报告比较和医生上下文。角色页面没有各自查询并拼接图表数据。
- 首页最多2张预览，点击“查看趋势”直接带入指标；成员360概览1张小趋势；健康数据1张主图。医生按关联风险指标和明确复核问题选择指标，默认最近30天，无近期数据就如实提示，不用历史数据冒充近期记录。
- 7天、30天、3个月、6个月、1年、全部统一；稀疏指标在3个月内不足两点时默认全部，并明确最后记录日期。基线默认当前管理周期。时间轴既有区间跳转仍适用。
- 变化箭头仅表示数值方向；百分比指标的绝对差用“个百分点”，不编造医学改善/恶化结论。

演示数据只改 `scripts/build_portfolio_demo.py`：增加匿名复查报告和相对当前时间的三组血压观测，保留年度基线冻结。UI 没有硬编码测量值。浏览器使用独立 `.runtime/chart_restore_demo.db`，没有写入普通开发数据库。
