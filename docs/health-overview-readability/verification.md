## 肉眼变化

1. 年度标题、确认状态、建立日期、资料覆盖和三阶段进度放入同一年度状态卡片；阶段图上方增加分割线。
2. “从年度基线到现在”单独加框；筛选、数值对比、趋势图与来源说明分层显示，图表增加指标小标题。
3. 当前重点关注使用白底双栏与领域分割线，仅状态标签采用浅黄；完整摘要、持续关注事项和历次记录均保留。
4. 底部拆成健康领域概览、资料完整性两张独立卡片。所有健康领域列入状态表，资料逐项标记已覆盖或待补充；部分覆盖信息保留。补充健康资料按钮位于右卡底部，完整资料入口作为本区次级内容保留。

四大区域之间实际间距均为28px。标题使用统一字号；当前Tab强化为医疗蓝。
