# 健康管理助手工作可视化验收

入口是今日工作中的健康管理助手卡片。卡片显示最近三项真实工作、当前等待对象、下一步和直接处理按钮。

详情顶部显示新报告接收时间、自动启动原因和责任健管。保留单层六步主流程；人工动作与单层工作时间轴并列。工作时间轴只读取既有事件、成功工具记录、确认记录和医生意见，不展示技术记录内容，不另建业务状态。

完成页显示入口、完成环节、实际创建数量、下一节点与负责人，并提供返回会员360、查看已创建事项。会员360使用最近更新的体检后管理进展。

## 真实浏览器

Chromium 从普通角色首页点击进入，使用合成演示库的隔离副本；未通过内部网址、会话注入或测试夹具打开业务页面。

1. 今日工作两张活动流程卡片。
2. 待健管确认：入口、六步流程、工作记录、继续后的去向。
3. 实际执行重新读取报告期间的运行提示；无假延时、无伪造状态。
4. 健管提交医生，显示资料准备记录与等待对象。
5. 会员360显示提交医生后的自动跟进。
6. 医生实际提交期间，显示接收意见并继续整理后续行动。
7. 原流程回到健管行动确认。
8. 确认后实际创建管理事项3、复查计划1、随访1、服务0；显示下一节点。
9. 返回会员360显示已完成和后续安排。
