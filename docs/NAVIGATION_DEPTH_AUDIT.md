# Executive HealthOps Navigation Depth Audit

审计基准：当前 working tree 的 `streamlit_app.py`。这里的“深度”只计算业务页面；列表中的选中记录、展开区、查看依据和 Inspector 都是同页内容，不增加导航层级。

## CURRENT TREE（已实现）

```text
成员健康中心
├─ 首页
├─ 健康 → 健康概览 / 健康数据 / 体检 / 医疗档案
├─ 历程
├─ 计划 → 当前方案 / 我的任务 / 阶段结果
└─ 服务 → 可用服务 / 我的申请 / 服务记录

HealthOps
├─ 今日
├─ 成员 → 概览 / 管理 / 健康 / 医疗 / 历程
├─ 医疗协同 → 内部医生 / 外部医疗
├─ 服务运营
└─ 更多 → 管理工具
```

## Depth Register

| 功能 | 一级 | 二级 / 同页内容 | 最终详情方式 | 深度 |
|---|---|---|---|---:|
| 上传体检 | 健康 | 体检 | 同页上传与报告详情 | 2 |
| 查看报告 / 对比 | 健康 | 体检 | 报告列表 + 详情 / 依据展开 | 2 |
| 健康数据 | 健康 | 健康数据 | 指标展开趋势 | 2 |
| 健康历程 | 历程 | 同页 Inspector | 1 |
| 医疗 / 手术详情 | 健康 | 医疗档案 | 同页 Inspector / 展开 | 2 |
| 成员风险处理 | 今日 或 成员 | 同页工作项 / 概览 | 同页详情 | 1–2 |
| 医生复核 | 医疗协同 | 内部医生 | 列表 + 详情 | 2 |
| 外部医疗 | 医疗协同 | 外部医疗 | 列表 + 详情 | 2 |
| 服务申请 | 服务 | 可用服务 | 同页详情与申请 | 2 |
| 服务履约 | 服务运营 | 同页工作列表 | 同页 Inspector | 1 |
| 查看依据 | 当前业务页 | 展开区 / Inspector | 同页 | 不增加 |

## Removed Navigation Layers

| 原路径 | 现在 |
|---|---|
| 健康档案 → 入口卡 → 体检 → 报告详情 | 健康 → 体检 + 报告列表/详情 |
| 成员 → 健康 → 健康历程内容切换 | 成员 → 历程 |
| 服务运营 → 成员 → 服务 → 申请详情 | 服务运营 + 同页服务 Inspector |

**验收标准：Depth 1/2 之外的主要业务导航为 0。**
