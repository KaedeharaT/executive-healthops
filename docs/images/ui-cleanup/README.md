## 实际浏览器

使用真实 Playwright Chromium。正式 `8501` 验证今日工作、会员列表、小明五个页签、年度和服务页面。上传、初评确认及合成红色风险在隔离 `8519` 验收库操作。删除弹窗已打开并取消，没有删除正式会员。正式库已备份，逐表记录数量及内容哈希核对无变化。

上传验收：上传一份合成问卷 → 自动整理56项 → 补充1项睡眠回答 → 确认初评 → 原处理完成；无需重新填写完整问卷。运行中有进度和动画，等待人工及完成状态不转动。

红色验收使用现有合成测试规则与 HealthEvent/Risk 流程，仅在隔离库生效，不改变临床规则。确认红色事项优先显示，医生列表与详情显示明确的人工责任。

## 信息减负

合并或移除7处重复呈现：今日侧栏“我的待办”、今日“新会员”重复入口、概览身份卡内重复下一步、概览重复开放事项、概览重复阶段目标文字、概览重复助手状态、报告看板重复完成出口。业务入口仍分别保留在会员列表、下一步、管理事项和唯一的报告处理区。

趋势、服务进度、最近记录、来源与整理依据保留为可展开内容；历程保持事件关联，并在每组中区分健康状态变化与管理/医疗动作，全部使用直线和直角连接。

截图所覆盖页面的可见主按钮均不超过1个。风险条使用中文、图标、色块与加粗边框；没有正式风险分级时使用中性状态，不假定低风险。医生等待不一律等同于红色。

## 验证范围

测试覆盖界面导航、单一上传入口、例外队列、同一目标继续处理、风险自主边界、医生责任、删除归档、时间轴关联、进度与等待状态。新增18项定向测试；既有文案断言随实际文案更新，业务状态断言保留。

Baseline：98 passed / 0 failed。最终联合回归：253 passed / 0 failed（扩大覆盖，未重跑全部仓库测试）。正式8501健康检查与8000文档返回200。

管理员技术诊断入口保留。浏览器和操作系统原生控件可能带有英文提示；普通业务界面的内部状态和助手用语按中文呈现。
